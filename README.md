1. Description du Projet

    1- Objectif : Vérifier la robustesse d'un mot de passe sans compromettre sa confidentialité.
    2- Technologie : Python 3, API REST, Bibliothèque hashlib.

2. Concepts de Sécurité Démontrés

    3- Hachage Cryptographique : Utilisation de SHA-1 pour masquer la donnée brute.
    4- K-Anonymat : Envoi partiel du hachage pour empêcher l'interception du secret par l'API tierce.

3. Comment l'utiliser

    5- Ajoutez une capture d'écran de votre terminal montrant le script en action (une fois avec un mot de passe sûr, une fois avec un mot de passe fuité comme 123456).
